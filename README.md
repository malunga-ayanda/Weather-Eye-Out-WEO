Weather Eye Out is a Docker container management and real-time system recourse monitoring service for servers, home or commercial.
It shows reliable realtime performance metrics along with all containers which you can run, stop, restart. The service can be accesed locally or remotely on port 3000 with other features in develoment.

Features Now:
1. Docker Infrastructure Management
2. CPU Speed Graph
3. Ram Usage Graph
4. Disk Usage Chart
5. Server Current Time
6. Server Up Time
7. Authentication

Stack: Node.js, Express.js, React, Recharts, Docker

Requirements:
1. Node.js (with NPM)

Setup Instructions:
1. Clone or Download and unzip the project to a folder e.g WEO
2. Open the folder "weo_server" using terminal e.g run this command : cd C:\Users\[your username]\Downloads\WEO\weo-server
3. Then run the command : npm install ( This Will install the required modules for the SERVER SIDE to run)
4. After its finished downloading Run the command: npm start (this will run the SERVER module on port 5000)
5. It will help to use a second terminal tab or window for the next part
6. Open the folder "weo_client" using terminal e.g run this command : cd C:\Users\[your username]\Downloads\WEO\weo-client
7. Then run the command : npm install ( This Will install the required modules for the CLIENT SIDE to run)
8. After its finished downloading Run the command: npm start (this will run the CLIENT module on port 3000)
9. After all is done you can now visit http://localhost:3000/ on the same device or http://[yourlocalip]:3000 for devices on same network or http://[yourwanip]:3000 for devices over the internet Port Forwarding Required for Wan
10. Login with default details username = PowerUser | Password = skullywagishere
